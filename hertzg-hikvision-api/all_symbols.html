Hikvision ISAPI: the alert stream and the documents a monitoring tool reads, from an NVR or a camera.

Examples

Print motion alerts with the channel's name

import { alertStream, inputProxyChannels, request, stream } from "@hertzg/hikvision-api";

const nvr = { baseUrl: "http://192.0.2.10", username: "admin", password: "hunter2" };
const names = new Map(
  (await request(nvr, inputProxyChannels)).map((channel) => [channel.id, channel.name]),
);

for await (const alert of await stream(nvr, alertStream, { signal: AbortSignal.timeout(60_000) })) {
  if (alert.eventType === "VMD" && alert.eventState === "active") {
    console.log(alert.at, names.get(alert.channel), "motion");
  }
}

Read a camera's motion grid

import { motionDetection, request } from "@hertzg/hikvision-api";

const camera = { baseUrl: "http://192.0.2.21", username: "admin", password: "hunter2" };
const motion = await request(camera, motionDetection({ channel: 1 }));

console.log(motion.grid?.map((row) => row.map((cell) => cell ? "#" : ".").join("")).join("\n"));

Every call carries the credentials to the resource's path

import { assertEquals } from "@std/assert";
import { resolvesNext, spy } from "@std/testing/mock";
import { deviceInfo, request } from "@hertzg/hikvision-api";

const fetch = spy(resolvesNext([
  new Response(
    "<DeviceInfo><model>DS-7608NI-Q2/8P</model>" +
      "<firmwareVersion>V4.75.207</firmwareVersion><deviceType>NVR</deviceType></DeviceInfo>",
  ),
]));
const nvr = { baseUrl: "http://192.0.2.10", username: "admin", password: "hunter2", fetch };

const info = await request(nvr, deviceInfo);

assertEquals(info.deviceType, "NVR");
assertEquals(fetch.calls[0].args[0], "http://192.0.2.10/ISAPI/System/deviceInfo");
const init = fetch.calls[0].args[1] as RequestInit;
assertEquals(new Headers(init.headers).get("authorization"), "Basic YWRtaW46aHVudGVyMg==");

Alert = { channel: number; eventType: string; eventState: string; eventDescription?: string; dateTime: string; at: string; activePostCount?: number; channelName?: string; ipAddress?: string; macAddress?: string; regions?: AlertRegion[]; pictureUrl?: string; pictureTransport?: string; }

One <EventNotificationAlert>, with the time it arrived.

  • activePostCount: number

    <activePostCount>: on an NVR, how many channels have an active event right now; 0 on the heartbeat. Not a count of posts.

  • at: string

    When the alert arrived, as an ISO 8601 string.

  • channel: number

    The channel the alert is about: <dynChannelID> when present, else <channelID>, else 0. On an NVR, IP cameras are 1..n; 0 is the NVR itself. A camera reports 1.

  • channelName: string

    <channelName>, which cameras send and NVRs do not.

  • dateTime: string

    <dateTime> as the device wrote it, zone or not. "" when missing.

  • eventDescription: string

    <eventDescription>, such as Motion alarm.

  • eventState: string

    <eventState>: active or inactive. VMD only ever posts active; smart events post inactive on some firmware when the rule clears.

  • eventType: string

    <eventType>, such as VMD, videoloss, fielddetection or linedetection.

  • ipAddress: string

    <ipAddress> of the device that posted.

  • macAddress: string

    <macAddress> of the device that posted.

  • pictureTransport: string

    <detectionPictureTransType>: url when the snapshot is at Alert.pictureUrl, binary when it follows as an image part of the stream.

  • pictureUrl: string

    <bkgUrl>: where to fetch the snapshot the device took for a smart event, with the same credentials (<URLCertificationType> says which scheme, usually digest). Sent when pictureTransport is url.

  • regions: AlertRegion[]

    The regions of a smart event, when the alert carries a <DetectionRegionList>.
